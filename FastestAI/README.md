# MiniCraft Fastest AI Assault

검수용 TestMap과 분리한 실제 컴까기 플레이용 맵 초안. 미니크래프트 또는 일반 크래프트 모드와 조합하는 빠른 자원 경제의 평지 섬멸전. 별도 AI 웨이브나 무료 병력 지급 없이 기본 섬멸전 AI를 사용하며, 미니크래프트의 강화 AI 옵션을 켜면 해당 모드의 AI가 추가 작동하도록 설계했다.

## 규칙
- 192×192 평지 권장, 실제 플레이 영역 최소 176×176.
- P1 사용자: 한 종족을 선택하여 일반 시작 유닛과 본진으로 시작.
- P2~P4 컴퓨터: 테란·저그·프로토스 각각 한 종족(에디터 플레이어 속성에서 지정), 정예 난이도 설정. 서로 동맹 및 시야 공유, P1과 적대.
- 전원 시작 광물 500, 가스 500.
- 본진 4개와 추가 확장 6개. 기지마다 광물 12덩이, 가스 4개, 각각 50,000 자원 목표.
- 적 팀 전멸 시 승리하도록 기본 섬멸전 승패 규칙 사용.
- 미니크래프트 자체 시작 옵션은 그대로 유지. 이 맵 자체는 배수·인구·일꾼 규칙을 덮어쓰지 않는다.

## 최초 생성
1. Galaxy Editor에서 192×192 평지맵 생성. 실제 플레이 가능한 경계를 확인한다. 절벽/장애물/기존 자원 및 유닛 배치 없이 빈 맵으로 준비한다.
2. 공허의 유산 멀티플레이 의존성을 설정한다. 미니크래프트 적용은 해당 로컬 모드를 의존성으로 추가한다(일반 크래프트와 동시에 적용하지 않음).
3. 플레이어 속성에서 P1 사용자, P2~P4 컴퓨터, P2~P4 종족 및 정예 AI 난이도를 지정한다. 시작 위치를 슬롯에 연결하고 고정한다. 플레이 영역의 아래 왼쪽 기준 176×176 예시 P1=(88,25), P2=(30,151), P3=(88,151), P4=(146,151). 실제 플레이 영역 높이가 다르면 적 기지는 위쪽 경계에서 25칸 떨어지게 설정한다. 다른 슬롯은 사용하지 않는다.
4. 기본 트리거를 모두 삭제하고 구성 요소 폴더 형식으로 저장한다. 중복 섬멸전 초기화를 방지하기 위해 빈 템플릿을 사용한다.
5. 해당 폴더를 Build-FastestAI.bat 위에 드래그한다. BAT 옆 MiniCraft-FastestAI.SC2Map 구성 요소 폴더가 생성된다. 원본과 기존 맵은 덮어쓰지 않는다.
6. 결과 폴더 ComponentList.SC2Components를 에디터에서 열고 사용자 지정 스크립트 FastestAI와 초기화 함수 MCT_Init를 확인하고 저장한다. 테스트 문서 실행 후 [Fastest AI] 로그를 확인한다. 트리거가 인식되지 않으면 루트 사용자 지정 스크립트에 FastestAI.galaxy를 붙여 넣고 초기화 함수 MCT_Init를 지정한다.

## 확인되지 않은 부분
완성된 에디터 패킹 .SC2Map 바이너리는 제공하지 않는다. 지형은 사용자의 빈 맵에서 가져오며 이 환경에서 실제 Galaxy Editor 컴파일/실행은 하지 못했다. 정예 난이도는 에디터/로비에서 설정하며 코드로 강제하지 않는다. 런타임 자원 배치 후 AI의 채취/멀티 인식, 실제 자원량 상한, 기본 승패 조건, 모드 시작 옵션과의 초기화 순서 및 AI 공격은 실게임 검증 필요. 공개 게시 전에 테스트할 것.
