# MiniCraft Test Arena (개발용)

미니크래프트 전용 테스트맵 생성기. EVO 및 본편 빌드 파일은 변경하지 않는다.

## 맵 구성
- 평평한 192×192 맵 권장 (실제 플레이 가능 영역 가로·세로 176 이상).
- 아래쪽: 플레이어 1이 테란, 저그, 프로토스 세 종족의 본진과 검수용 유닛 및 건물을 모두 소유.
- 위쪽: 플레이어 2 테란, 3 저그, 4 프로토스. 서로 동맹 및 시야 공유, 플레이어 1과 적대.
- 각 본진 광물 10덩이, 가스 2개, 각 자원 100,000 목표. 시작 광물 및 가스 각각 10,000. 플레이어 1 인구 상한 500 요청(모드의 자체 옵션에 의해 바뀔 수 있음).
- 순정 섬멸전 AI 초기화와 정예 난이도 값 7 요청. 실제 난이도 및 AI 공세 시점은 엔진 확인 필요.
- 검수용 배치 162종 고유 ID(변신 상태, 임시 개체 포함). 존재하지 않는 카탈로그 ID는 건너뛰고 로그 출력. 모든 스킨 및 캠페인/협동전 유닛 전수 배치는 아님.

## 최초 1회 빈 맵 준비
1. Galaxy Editor에서 새 192×192 평지맵 작성. 언덕, 절벽, 장애물, 기존 배치 유닛은 불필요.
2. 공허의 유산 섬멸전 의존성 및 테스트할 로컬 MiniCraft(또는 NormalCraft) 의존성 설정. 둘을 동시에 쓰지 않는다.
3. 플레이어 속성에서 P1 사용자, P2~P4 컴퓨터 지정. AI 난이도는 정예 선택. 시작 지점을 남쪽 중앙 및 북쪽 왼쪽·중앙·오른쪽으로 넓게 띄워 배치하고 플레이어 슬롯에 연결. 플레이 가능 영역의 아래 왼쪽 기준 추천 위치 P1=(88,25), P2=(30,145), P3=(88,145), P4=(146,145). AI 위치는 모서리에서 최소 14칸 떨어지도록 한다.
4. 트리거 편집기에서 기본 Melee Initialization 등 모든 기본 트리거를 제거한다(중복 초기화 방지).
5. 구성 요소 폴더 형식으로 저장하고 에디터를 닫는다.

## 자동 생성 및 실행
저장한 빈 맵 폴더를 저장소의 Build-TestMap.bat 위에 드래그한다. BAT가 GitHub 최신 스크립트를 받아 옆에 MiniCraft-TestArena.SC2Map 구성 요소 폴더를 생성한다. 기존 원본은 유지된다. 결과 폴더가 이미 있으면 덮어쓰지 않는다.
생성된 ComponentList.SC2Components를 에디터로 열고 트리거 편집기에서 MiniCraftTestArena 사용자 지정 스크립트 및 초기화 함수 MCT_Init를 확인한다. 다른 이름으로 저장해 MapScript를 재생성한 후 테스트 문서 실행.
자동 트리거 인식이 안 될 경우 새 루트 사용자 지정 스크립트를 만들고 MiniCraftTestArena.galaxy의 전체 내용을 넣은 후 초기화 함수 MCT_Init를 지정한다.
미니크래프트 시작 옵션은 해당 모드의 기존 설정이 동작하는 경우 그대로 사용 가능하다.

## 검증 상태
이 코드는 개발용 초안이며 실제 Galaxy 컴파일이나 게임 실행을 확인하지 못했다. 빈 맵 템플릿 없이 지형 바이너리를 생성하지 않는다. AI 실제 공세, 혼합 종족 생산·기술 제한, 부속건물과 가스 연결, 자원량 한계, 특수/임시 유닛의 자동 소멸, 인구 상한, 사용자 지정 스크립트 XML 인식은 미검증. 자동으로 부착되지 않은 부속건물·가스 건물은 직접 건설로 확인한다. 게임 채팅 및 트리거 디버그의 [MiniCraft Test] 로그를 확인한다.
