# 시작 옵션 실험판 (2026-11-26)

Classic 전용. BAT는 `Triggers`, `CGame/TriggerLibs`, 라이브러리 Galaxy 파일을 자동 생성/등록한다. 이전 수동 초기화가 감지되면 중복 등록하지 않고 기존 설정을 유지한다. 이전에 원문을 직접 붙여넣은 경우에는 직접 최신 소스로 교체해야 한다. Galaxy Editor에서 문법 검사와 저장 및 비공개 테스트 필수. 실제 네이티브 컴파일은 미검증이다.

| 옵션 | 구현 범위 |
|---|---|
| 크래프트 | v0.1.16부터 별도 MiniCraft/NormalCraft 프로필. 시작 메뉴에는 로드된 프로필 표시; 경기 내 전환 미구현 |
| 생산 | 1~8배, 유닛 생성 이벤트의 명시적 일반 생산 허용 목록에 한함. 변태/소환/요격기/보급 제공 유닛/모선 제외. 복제 유닛의 집결지 명령과 배치 검증 필요 |

# MiniCraft AI v0.1.10 — 실험용 활성화 및 검증

이 모듈은 기존 섬멸전 AI에 운영 보조 로직을 추가합니다. 현재 Galaxy 네이티브 컴파일/실제 게임 검증은 하지 못했습니다. 초기화가 연결되지 않으면 순정 AI 그대로 동작합니다.

## 적용 (최초 1회)

1. 기존 Build-MiniCraft.bat 실행. 자동 백업 후 모드 구성 요소 폴더의 Base.SC2Data/TriggerLibs/MiniCraftAI.galaxy가 갱신됩니다.
2. 에디터에서 기존 MiniCraft 구성 요소 폴더를 열고 트리거 모듈(F6)에서 모드용 라이브러리를 생성하거나 기존 전용 라이브러리를 선택합니다.
3. 라이브러리에 Custom Script 요소를 추가하고 아래 코드를 넣습니다. 에디터가 외부 스크립트를 인식하도록 가져오기 관리자/구성 요소 경로를 확인합니다.

```galaxy
include "TriggerLibs/MiniCraftAI"
```

4. Custom Script의 Initialization Function에 `MiniCraftAI_Init`를 지정합니다(함수명만). 해당 입력란이 없는 경우 맵 초기화 트리거의 Custom Script 액션에서 `MiniCraftAI_Init();`를 한 번 호출합니다. 중복 호출은 방지되어 있습니다. include 방식이 인식되지 않을 경우 Galaxy 파일 본문을 Custom Script에 붙여넣는 수동 대안도 있으나 이후에는 직접 갱신해야 합니다.
5. 스크립트 검사 후 저장 및 비공개 게시. 오류 발생 시 기존 백업으로 돌아가고 컴파일 오류 전문을 기록합니다. **에디터가 외부 파일을 저장 과정에서 누락시키는지도 확인하십시오.**
6. 기존 섬멸전 초기화/AI 시작을 제거하지 않습니다. 정예(비치터), 핸디캡 100%로 비교 테스트합니다. 기존 치터 난이도의 보너스를 제거하는 모드는 아닙니다.

## 정책 및 안전장치

- 4 게임 초 주기, 활성 컴퓨터 및 섬멸전 기지가 있는 경우만 처리.
- AI stock 목표 배율 3.0/4.0는 절대값 설정으로 적용. 반복 곱셈 금지. 순정 난이도별 스크립트에서 해당 API를 읽는지는 테스트 대상.
- 생산/건설 요청은 AITechCount(대기열 포함), 내부 요청 대기열, 시간 제한을 확인. 건설 요청 간 최소 4 게임 초, 병력 요청 간 최소 4 게임 초, 확장 시도 간 최소 100 게임 초.
- 저그는 추가 부화장·여왕을 요청하지만 자동 애벌레 생성 또는 주입 성공은 엔진 AI가 담당.
- 적 공중 유닛은 AIKnownUnitCount로 확인. 전 맵 적 유닛을 직접 검색하지 않음.
- 시야/회피/수리/가스/후퇴 등의 기본 난이도 플래그 활성화, APM 600 시범 상한. 실제 난이도 선택 UI는 바꾸지 않음.
- 실제 유닛/건물 생성, 무료 자원, 기존 플레이어 데이터 조작, 기존 AI 대기열 강제 삭제 없음.

## v0.1.10 — 대규모 물량전 AI 재조정

- 실플레이 피드백(3기지에 관문 20·로봇공학 3·우주관문 6)을 기준으로 목표식 조정: 병영/관문 목표 min(48, 2 + 기지×6 + 광물÷550), 군수공장 18, 우주공항 16, 로봇공학 14, 우주관문 20, 부화장 24, 여왕 24를 시범 상한으로 설정.
- 건설 요청 간격 12→4 게임 초, 같은 유형 미완료 건설 최대 3, 내부 건설 대기열 상한 12, 생산 대기열 상한 32, 병력 묶음 요청 최대 24(인구·기지에 따라 축소). 목표 병력 배율 3.0/4.0, 일꾼 기지당 24(최대 128), 확장 목표 상한 8.
- 생산시설 유형을 순환해 관문/병영 증설이 고급 생산시설 요청을 독점하지 않도록 조정. 가스 부족 기준 450, 보급 여유 확대, 프로토스 공허 포격기 추가 생산 경로. 실제 생산량·가동률을 계측해 제어하는 로직은 아직 없음.
- 기존 BAT/초기화 절차 유지. 무료 자원/유닛 추가 없음. Galaxy 컴파일, 엔진 대기열 의미, 가스 채취, 실제 3종족 및 4대4 성능 미검증. 상한은 건설 보장이 아니다.
